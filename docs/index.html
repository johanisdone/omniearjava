OmniEar

Real-time acoustic threat detection for the desktop. OmniEar classifies short audio windows with an ONNX CED-mini model and raises prioritised alerts for gunshots, explosions, screams, impacts, sirens and breaking glass — fully offline, processed in memory.

What it does

Live dashboard

Device picker, input level meter, per-category score bars with threshold markers and a prioritised alert history with CSV export.

Explainable decisions

Per-category thresholds, optional moving-average score smoothing, and N-of-M window confirmation with a cooldown.

Glass-break detector

A dedicated high-frequency DSP heuristic runs alongside the model to catch impulsive glass breakage.

Command line + eval

Replay a WAV, capture or record from a microphone, and run a labelled evaluation harness that reports accuracy and macro F1.

Run it

Download the latest omniear.jar from the Releases page, then launch the dashboard: 

copyjava -jar omniear.jar --gui

Requires Java 21 or newer. Prefer to build from source? Clone the repo and run ./mvnw -DskipTests package (Windows: mvnw.cmd).
